# homebrew-gridelio

Homebrew tap for **Gridelio** — a macOS window manager (snap layouts, workspaces, automatic rules).

## Install

```bash
brew tap gaorfg-bit/gridelio
brew install --cask gridelio
```

## Update

```bash
brew upgrade --cask gridelio
```

## Notes

- The app is **not notarized yet**, so macOS Gatekeeper may warn on first launch
  ("unidentified developer"): **right-click the app → Open**, once.
- Requires **macOS 14 (Sonoma)** or later.
- Source / download: <https://gridelio.com>
